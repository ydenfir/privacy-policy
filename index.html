Politique de confidentialité

Dernière mise à jour : 10 septembre 2026

Cette politique de confidentialité s'applique à l'application Hub et aux applications métier de l'écosystème personnel développé par Yanis Denfir qui utilisent un compte utilisateur et le serveur personnel décrit ci-dessous (ci-après « les applications »). Ces applications sont développées et maintenues par un développeur indépendant pour un usage privé, au sein d'un cercle restreint d'utilisateurs connus (famille, proches).

Certaines applications métier de l'écosystème fonctionnent entièrement en local, sans compte ni serveur : leurs pratiques de données sont différentes et décrites dans une page dédiée propre à chaque application (voir sa fiche Play Store pour le lien exact) plutôt que dans ce document.

1. Qui est responsable du traitement des données

Les applications sont développées et exploitées par Yanis Denfir, à titre personnel et non commercial. Le serveur qui héberge les comptes utilisateurs et les données décrites ci-dessous est un serveur personnel, sous le contrôle exclusif du développeur.

Contact : mypykata@gmail.com

2. Données collectées

Les applications collectent uniquement les données nécessaires à leur fonctionnement :

  • Adresse e-mail : utilisée comme identifiant de compte et pour la connexion.
  • Mot de passe : stocké de façon sécurisée sur le serveur, jamais transmis ni partagé en clair.
  • Droits d'accès aux applications : la liste des applications de l'écosystème auxquelles votre compte a accès, gérée par l'administrateur de l'écosystème.
  • Jeton de session : un identifiant technique temporaire permettant de rester connecté entre les applications de l'écosystème (mécanisme de connexion unique piloté par le Hub), stocké de façon sécurisée sur votre appareil.

Les applications ne collectent aucune donnée à des fins publicitaires et n'intègrent aucun outil d'analyse d'audience ni de traceur tiers (pas de Firebase Analytics, pas de SDK publicitaire).

3. Utilisation des données

Les données ci-dessus sont utilisées exclusivement pour :

  • vous authentifier et maintenir votre session connectée entre les applications ;
  • déterminer quelles applications de l'écosystème vous sont accessibles ;
  • afficher les informations liées à votre compte dans les applications.

4. Partage des données

Vos données ne sont ni vendues, ni partagées, ni transmises à des tiers. Elles sont hébergées sur un serveur personnel, sans service tiers intermédiaire (pas d'hébergeur cloud commercial, pas de service d'analyse externe).

5. Conservation des données

Vos données sont conservées tant que votre compte existe sur le serveur. Vous pouvez demander la suppression de votre compte et de l'ensemble des données associées à tout moment, par simple demande à l'adresse de contact indiquée ci-dessus.

6. Vos droits

Vous pouvez à tout moment demander :

  • l'accès aux données vous concernant ;
  • la correction de données inexactes ;
  • la suppression de votre compte et de vos données.

Pour exercer ces droits, contactez : mypykata@gmail.com

7. Utilisation par des mineurs

Ces applications ne sont pas destinées à un usage grand public et ne sont pas spécifiquement conçues pour des enfants. L'accès est réservé aux personnes explicitement invitées par l'administrateur de l'écosystème.

8. Modifications de cette politique

Cette politique de confidentialité peut être mise à jour si le fonctionnement des applications évolue. La date de dernière mise à jour figure en haut de cette page.

9. Contact

Pour toute question relative à cette politique de confidentialité ou à vos données personnelles : mypykata@gmail.com
